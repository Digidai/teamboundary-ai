# TeamBoundary AI name screening

## Status and scope

`TeamBoundary AI` is the public project name and `teamboundary-ai` is the repository/package slug.
The name describes the product's purpose: an AI workspace where team and tenant boundaries are
explicitly enforced.

This file records a preliminary public-source screen performed on 2026-08-08 (Asia/Shanghai). It is
not a legal opinion, trademark clearance, freedom-to-operate conclusion or promise that a name,
domain or account remains available.

## Exact-name screen

At the time of review:

- GitHub returned zero repositories with `teamboundary-ai` or `teamboundary` in the repository name,
  and the `teamboundary` user endpoint returned not found;
- npm returned not found for both `teamboundary-ai` and `teamboundary`;
- PyPI, RubyGems and NuGet returned not found for `teamboundary`;
- the crates.io request was access-blocked during the check and is therefore recorded as
  **inconclusive**, not clear;
- public RDAP returned not found for `teamboundary.com`, `.org`, `.dev` and `.io`; and
- the `.ai` registry WHOIS response was `Domain not found` for `teamboundary.ai`.

Exact quoted web searches for `TeamBoundary AI` did not identify an AI/software product using that
exact name. Results for the spaced phrase `team boundary` were primarily academic or descriptive
uses. Descriptive phrase use can still create weak distinctiveness or unindexed common-law risk.

## Rejected nearby directions

- `TeamPrompt` is already used by AI prompt-management/workspace products:
  <https://teamprompt.app/help> and <https://www.teamprompt.cc/>.
- `Cowork` is crowded by existing AI products, including Microsoft Copilot Cowork and Cowork AI:
  <https://support.microsoft.com/en-us/Microsoft-365-Copilot/get-started-with-cowork> and
  <https://coworkai.app/>.
- Generic names built only from `team`, `workspace`, `prompt` or `AI` were rejected because they are
  difficult to distinguish and search.

## Public-source decision

The preliminary exact-name screen is sufficient for a cautiously described open-source source
release under the unregistered project identifier. It is not sufficient for a trademark filing,
paid hosted service, marketplace listing, fundraising claim or material brand spend.

Before commercial brand use, qualified trademark counsel should search exact, visual, phonetic,
translated and conceptual similarity in every intended market, including Nice classes 9 and 42
(and class 35 if applicable), common-law use, company names, app stores, social accounts and domain
history. The owner must also repeat the registry and web checks because results can change at any
time.

Public materials must not say `registered`, `trademark cleared`, `conflict-free`, `guaranteed
available` or equivalent. If a material conflict is later found, the project will follow the rename
procedure in [TRADEMARKS.md](TRADEMARKS.md).
